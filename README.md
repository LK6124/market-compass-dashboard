# 沪深市场资金温度看板

这是一版可自动更新、适合手机查看的静态看板。数据由 GitHub Actions 每个工作日北京时间 20:30 抓取，发布到 GitHub Pages 后，电脑和手机都可以通过同一个网址访问。

## 一次性部署

1. 在 GitHub 新建一个仓库。希望使用 GitHub 免费版 Pages 时，仓库需要设为 **Public**。
2. 把本目录中的全部文件上传到仓库根目录，包括隐藏的 `.github` 文件夹。
3. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 中将 **Source** 设为 **GitHub Actions**。
4. 打开 **Actions → 每日更新并发布看板 → Run workflow** 手动运行一次。
5. 运行结束后，在 Actions 的部署结果或 **Settings → Pages** 中取得网址，形如 `https://用户名.github.io/仓库名/`。

在手机上打开该网址后，建议使用“添加到主屏幕”，之后可以像 App 一样进入。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm run update
npm run serve
```

然后打开 `http://localhost:4173`。

## 自动更新方式

- 每个工作日北京时间 20:30 自动执行一次。
- 行情来自腾讯行情，两融数据来自东方财富数据中心，沪深300 PE 来自蛋卷，10 年期国债收益率来自东方财富。
- 抓取成功后会同时更新 `data.json` 和离线回退文件 `data.js`，随后发布静态网站。
- 如果数据接口异常，工作流会失败并保留上一次可用的数据，不会发布残缺行情。
- 需要在 Actions 页面手动刷新时，运行 **每日更新并发布看板** 即可。

修改更新时间时，编辑 `.github/workflows/deploy.yml` 中的 cron。cron 使用 UTC，北京时间减去 8 小时，例如北京时间 21:00 对应 `0 13 * * 1-5`。

## 页面刷新

页面部署到 HTTPS 后，会通过 `data.json?ts=当前时间` 强制读取最新快照。手机浏览器重新打开或下拉刷新即可看到当天数据。

## 数据口径

- ETF 占比：`510300 / 510310 / 510330 / 159919` 四只ETF场内市值合计 ÷ 沪深300流通市值，属于估算口径。
- 两融余额：沪深两市融资融券余额，交易所 T+1 披露。
- 股债利差：`100 ÷ 沪深300市盈率(TTM) − 中国10年期国债收益率`，均线与 ±2σ 使用 2.5 年滚动窗口。
- 页面仅供个人数据跟踪，不构成投资建议。
